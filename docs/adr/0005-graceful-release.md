# 5. Остановка по сигналу возвращает задачу без траты попытки

Статус: принято

## Контекст

Выкатка перезапускает воркеры. Если каждая выкатка съедает попытку, задача с
тремя попытками умирает после трёх выкаток, ничего не сделав.

## Решение

По `SIGTERM` и `SIGINT`: новые задачи не берём, текущим даём доработать до
крайнего срока, остаток возвращаем в очередь с уменьшением счётчика попыток.

## Почему

Попытка - это мера доверия к задаче, а не счётчик перезапусков. Задача не
виновата в том, что мы выкатили новую версию.

## Чем платим

Теоретически можно зациклить задачу, перезапуская воркер в нужный момент. На
практике это требует намеренных действий, а не случайности.

## Проверяется

Тестом, который поднимает настоящий процесс воркера и убивает его двумя
способами: `SIGKILL` - попытка потрачена, `SIGTERM` - нет.
