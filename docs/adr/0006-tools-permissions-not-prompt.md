# 6. Права агента выданы перехватом вызова, а не текстом в промпте

Статус: принято

## Контекст

Агенту нужно ограничить, что он может делать. Простой путь - написать в
системном промпте: «не изменяй данные без подтверждения».

## Решение

Список разрешённых инструментов на каждого агента, отдельный выключатель записи
и подтверждение человека на необратимые действия. Проверка стоит в точке вызова
инструмента.

## Почему

Инструкцию в промпте можно переспорить другой инструкцией. Она приходит из
данных, которые агент читает: письмо, страница сайта, файл клиента. Перехватчик
переспорить нельзя - он не читает текст.

Агент видит только разрешённые ему инструменты, иначе он тратит шаги и деньги,
прося недоступное.

## Чем платим

Список прав надо вести руками, и он расходится с реальностью, если про него
забыть. Отсюда правило: новый инструмент по умолчанию не разрешён никому.

## Проверяется

Тестом, где агенту на чтение подсовывают сценарий с записью: запись не проходит,
данные не меняются, задача при этом не падает.
