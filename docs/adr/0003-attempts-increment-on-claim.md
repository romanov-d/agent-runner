# 3. Попытка считается в момент захвата

Статус: принято

## Контекст

Счётчик попыток можно увеличивать в двух местах: когда задачу взяли, или когда
обработчик её провалил.

## Решение

Увеличиваем в момент захвата, одной командой с переводом в работу.

## Почему

Воркер может умереть до первой строчки обработчика: нехватка памяти, выкатка,
падение машины. Если считать попытку в обработчике, такая задача никогда не
потратит ни одной и будет убивать воркеров по кругу.

Задача, роняющая процесс, - самый опасный вид задачи. Счётчик в момент захвата
гарантирует, что она умрёт после `max_attempts`, а не унесёт с собой очередь.

## Чем платим

Остановка по сигналу тоже выглядит как потраченная попытка, хотя задача не
виновата. Поэтому есть отдельный возврат, который попытку возвращает
(см. 0005).
